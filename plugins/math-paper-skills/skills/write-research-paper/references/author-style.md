# Author style configuration

This entry point contains no personal author profile or source-paper corpus.
Use explicit current directions, the manuscript's established conventions, and
venue requirements. Do not infer personal preferences from this template.

A host project may designate a private profile, for example `docs/STYLE.local.md`.
Read that profile for authorized writing work. Independent readers receive only
an explicitly allowed, frozen style contract containing no writer state.
If no profile is designated, apply the shared paper-writing guide and report
that no personal style profile was used. A missing optional profile does not
block ordinary manuscript work.

Record personal choices outside this distributable skill. Separate explicit
author decisions from observations across representative papers and from venue
requirements. Historical frequency is advisory and does not override current
instructions. Do not publish source excerpts, paths, corpus manifests, or private
proof decisions with the skill.

Mathematical exposition should make assumptions, quantifier scope, dependencies,
representatives, and derived objects explicit where they carry an inference.
Preserve correct author wording. When a formula is load-bearing, state or cite
it precisely. Do not impose one author's punctuation, vocabulary, typesetting,
bibliography, or disclosure wording on another author.

Before requesting more proof detail, apply the manuscript's scoped decisions
under [the proof-detail policy](owner-proof-decisions.md). These decisions do not
certify correctness and are not manuscript prose.

An [optional concrete example](../../../examples/author-style.md) is available
for explicit adoption and customization. Do not load or apply that example as
a default, and do not infer that its preferences belong to the current author.
